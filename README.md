# Zen Timer 黑白专注计时器

一款专为 iPad 横屏与全屏学习场景设计的极简黑白专注计时器，集成今日/明日计划清单、专注记录、趋势统计与本地数据备份。

## 在线使用

[打开 Zen Timer](https://lifengian.github.io/zenflip-focus-clock/)

## 主要功能

- 黑色背景、白色等宽数字的全屏计时器
- 纯 `HH:MM:SS` 显示，不包含翻页卡片和单位文字
- 数字切换使用 GPU 合成的透明度与位移动效
- 精确记录小时、分钟和秒
- 开始、暂停、继续、保存与放弃本次专注
- 今日与明日任务清单
- 每日专注记录与趋势统计
- 数据导出与导入
- 屏幕常亮支持
- PWA 离线缓存
- 适配 iPad 横屏、竖屏和主屏幕启动

## 安装到 iPad

1. 使用 Safari 打开在线地址。
2. 点击 Safari 工具栏中的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 开启“作为网页 App 打开”，然后点击“添加”。

首次成功打开后，应用会缓存到设备。计时记录、任务和统计数据均保存在当前设备的浏览器本地，不会上传到 GitHub。

## 隐私

Zen Timer 不包含账号系统、广告或第三方分析服务。所有学习数据默认仅保存在使用者自己的设备中。
